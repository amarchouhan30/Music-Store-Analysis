# 🎵 SQL Project: Music Store Analysis

## 📌 Project Overview

This project uses **SQL** to analyze data from an online music store. The main objective is to explore the store's sales data, identify important business trends, and answer key questions that can help improve business decisions.

The project demonstrates practical SQL skills such as:

- Data analysis
- Data filtering
- Aggregation
- Grouping
- Sorting
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Business-oriented SQL queries

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze music purchasing patterns.
- Identify the most popular music genres.
- Find the most popular artists and songs.
- Analyze music prices.
- Identify countries with the highest number of purchases.
- Generate useful business insights from the available data.
